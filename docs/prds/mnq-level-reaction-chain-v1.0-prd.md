# MNQ Level 反应预测链

## 目标

在 MNQ 开盘行情和盘中行情中分别维护上端链、下端链。用户事前选择固定 Level、填写预期反应和接受确认条件。当前 Level 的实际结果确认“突破并接受”或“跌破并接受”后，系统自动激活事前写好的下一 Level。

## 已确认规则

- 后续 Level 必须提前写好。
- Level 从 PDH、PDL、PDC、PMH、PML、ONH、ONL、VWAP、DL（15M）、DH（15M）、盘前 FGV、Day Level 中选择，也允许自定义。
- 参考价格可选，不设为必填。
- 每个 Level 必须选择 1M、5M、15M 或 30M 判断周期，用于说明预期反应按哪个周期确认；旧记录可补录。
- 每个时段分别维护上端链和下端链。
- 实际反应与接受类预期一致时立即开放下一节点；准确性独立记录，不参与下一层开放条件。
- 未触及不进入正确率分母，也不激活下一节点。
- 实际反应未形成预期中的接受时暂停链条。
- 已激活的后续节点锁定事前计划字段，防止盘后重构。
- 实际判断正确时，实际 Level 自动关联对应的预计 Level。
- 实际判断部分正确或错误时，必须从同一套预设中选择实际 Level、选择实际判断周期并填写偏差说明；选择自定义 Level 时补充名称。
- 预计链包含多层 Level 时，实际判断按同样层数逐层录入；上一层确认接受后立即开放下一层，同一次保存可完成多层判断。

## 存储

预测链作为 `levelForecasts` 写入现有 `marketOpenJson` 和 `marketMidJson`，不修改 Prisma Schema，不要求数据库迁移。

## 状态

```text
PLANNED → ACTIVE → COMPLETED
                   ├─ 接受成立 → 激活下一 PLANNED 节点
                   ├─ 未触及   → 链条结束，不评分
                   └─ 判断偏差 → PAUSED
```

每个节点保存 `plannedAt`、`activatedAt` 和 `completedAt`，用于区分事前计划与实际触发。

## 验收场景

- `PDH → PMH`：PDH 预期和实际均为突破接受，保存后 PMH 激活。
- `VWAP → ONL`：VWAP 预期和实际均为跌破接受，保存后 ONL 激活。
- 预期突破接受、实际拒绝：下一 Level 不激活，链条暂停。
- 当前 Level 未触及：不计错误，下一 Level 不激活。
- 上端链和下端链可独立推进。
- 两层预计链可在同一次实际判断中依次填写并完成。
- 判断正确时无需重复填写实际 Level；判断偏差时实际 Level 不能为空。
- 旧记录没有 `levelForecasts` 时正常打开和保存。
- 今日汇总的“MNQ 分时行情复盘”分别展示开盘行情、盘中行情的总体预计/实际，以及每个 Level 的判断周期、预计反应、确认依据和实际结果。
- 今日汇总根据上下端预计路径与实际 Level 结果，为开盘行情和盘中行情分别生成 Level 行情总结，并说明正确、偏差、未触及及最深推进层级。

## 工程约束

- 状态推进集中在纯函数中，React 组件只负责输入和展示。
- 不安装新的第三方依赖。
- 必须通过格式检查、类型检查、Lint 和生产构建。
