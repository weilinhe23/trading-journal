# KPI 累计实现 PTS 周期对比实施方案

日期：2026-09-05

分支：`codex/kpi-pts-period-comparison`

状态：已实现

## 目标与现状

在 `/kpi` 增加任意时间范围内的周、月、季度趋势查询，并支持任选多个同粒度周期叠加比较累计实现 PTS。所选周期可以不连续、可以跨年；上一周期对比作为快捷入口。

现有 `KpiTrendExplorer.tsx` 支持历史单周期查询，`KpiCumulativeChart.tsx` 展示单条累计曲线，`/api/kpi/summary` 返回单周期数据。复用现有日期选择与 Recharts 样式，保留半年度、年度的单周期功能。

## 查询与图表交互

提供“单周期 / 范围趋势 / 周期叠加”三种视图。

### 范围趋势

- 选择开始日期、结束日期和统计粒度：周、月、季度。默认最近 4 个自然周（本周及之前 3 周），本周只累计到美东今天。
- 快捷按钮包括最近 4 周、最近 12 周、最近 12 月和最近 8 季度，当前匹配的范围高亮显示。直接进入 `/kpi` 默认最近 4 周；携带查询参数的链接和刷新保留明确选择。
- 查询范围自动扩展到起止日期所属自然周期的边界，并显示实际统计范围，避免边界半个月与完整月份混比。
- 横轴按真实时间排列各周、月或季度，柱形展示各期累计实现 PTS，叠加全期基准与乐观目标线；每期独立累计，不从查询起点不断累加。
- 展示指标支持累计 PTS、全期目标完成率、日均 PTS。可开启连续 4 个完整且无漏录周期的移动平均，未结束周期不参与。
- 顶部展示当前周期累计、截至今天的目标差额、日均 PTS、每日基准达标率。目标随每日设置生效日期逐日累加；区分全期目标和当前进度目标。
- 提示框显示周期范围、累计 PTS、录入完整度，以及相较紧邻上一自然周期的差额和适用时的环比百分比。首期可额外读取上一期作为比较基数，但不增加范围外的图表点。
- 无记录周期保留在横轴并显示缺口，不当作零收益，也不跳过它去比较更早有记录的周期。
- 进行中的周期注明“截至 ET 日期，未结束”。与上一完整周期的比较明确标注口径。

### 周期叠加

- 从查询范围内勾选多个周期，也可通过周期选择器添加范围外的任意周期。支持跨年、不连续选择。
- 一次比较使用同一粒度：周对周、月对月、季度对季度。切换粒度后清除旧选择，提示重新选择。
- 例如：对比 2026 年 1 月、3 月、6 月；或对比 2025 Q4、2026 Q1、2026 Q3。
- 每个周期一条累计曲线，横轴为“第 N 个交易日”，纵轴为累计 PTS，包含零基线。以不同颜色、线型和文字图例区分周期。
- 至少选择 2 期；首版建议最多同时叠加 6 期以保持可读性，范围趋势仍支持查看更长历史。选择上限在界面和接口中保持一致。
- 可指定任一已选周期为基准；默认最早所选周期。摘要表展示各期累计、相对基准的 PTS 差额和适用时的变化率。
- 非相邻周期称“较基准变化”，只有紧邻上一自然周期的比较称“环比”。
- 提供“本期与上期”快捷选择，以及“同进度 / 整期”口径切换。默认同进度。
- 悬浮提示展示各期对应日期、当日值、累计值及录入状态。图例可隐藏曲线，隐藏仅影响展示，不改变已选集合、比较进度或基准；移除周期才重新计算。

查询范围、粒度、所选周期、基准与比较口径写入 URL，刷新后保留。加载、失败重试、无数据及移动端布局均需覆盖；快速切换取消旧请求，避免旧结果覆盖新选择。

## 数据与计算口径

- 数据源沿用 `KpiDailyRecord.actualPcts`。字段名虽含 Pcts，界面单位是 PTS，不是百分比。
- 比较用户每日录入的 KPI 实现点数，不混入成交明细推导的点数。自动成交汇总如后续需要，另行确定分批执行、数量和手续费口径。
- 每期从零开始，逐交易日累加，允许负数和回撤。聚合、周期对齐、差值和变化率全部在后端计算。
- 周采用周一至周日，月采用自然月，季度采用 Q1–Q4；支持跨年。
- 默认日期取美东日期；数据库日期键按 UTC 零点表达该交易日，避免再次转换时区导致日期前移。
- 沿用项目交易日工具过滤周末和休市日，实现前核对跨年边界行为。

| 场景 | 展示与计算 |
| --- | --- |
| 叠加：同进度 | N 为所有已选周期截至 ET 今天已到达的交易日数的最小值。摘要比较前 N 日，在图中画比较截止竖线；完整曲线仍保留，方便观察后续走势。 |
| 叠加：整期 | 每期展示自身全部已到达交易日的数据。进行中的周期标记未结束，不称同进度比较。 |
| 周期长度不同 | 整期曲线按交易日序号对齐，短周期结束后返回 null，不延长成水平线。 |
| 未录入日期 | 已到达日期可沿用已有累计值，但提示未录入；第一条记录前保持 null。摘要显示已录入/应录入日数，有缺失标记数据不完整，差额注明基于已录入值并隐藏变化率。 |
| 显式录入 0 | 视为已录入，与缺失区分。 |
| 整期无记录 | 返回 null，显示暂无记录，不计算差额或变化率。 |
| 未来周期 | 显示尚未开始，不绘制未来收益，不允许加入叠加比较；跨越未来的查询范围可保留空周期位置。 |
| 基准值大于 0 | 双方在比较窗口内数据完整时，变化率 =（比较值 − 基准值）÷ 基准值 × 100%。 |
| 基准值小于或等于 0 | 显示 PTS 差额，变化率显示“—”，解释基准非正。 |

例如：选择 1 月、3 月、6 月，最短周期有 20 个已到达交易日，同进度模式比较各自前 20 个交易日。若其中包含本月且目前仅到第 8 个交易日，则所有选中周期比较前 8 个交易日。

范围趋势默认展示各期整期结果；其相邻变化基于整期（未结束周期截至今天）。同进度仅用于叠加视图，两个视图明确标注口径。

## 实现拆分

### 服务端数据与接口

- 新增 `src/lib/kpi-comparison.ts`：严格日期校验、周期枚举与归一化、去重、逐日累计、多周期对齐和摘要纯函数。
- 在 `src/lib/kpi-comparison-server.ts` 实现范围与多周期查询，按所需日期区间读取 KPI 日记录；跨年查询不依赖仪表盘只查询当年的逻辑。
- 新增 `GET /api/kpi/trends?period=month&from=2026-01-01&to=2026-06-30`，支持 week、month、quarter，返回归一化范围和按时间排序的各期摘要及相邻变化。
- 新增 `GET /api/kpi/comparison?period=month&anchors=2026-01-01,2026-03-01,2026-06-01&baseline=2026-01-01&mode=aligned`，mode 支持 aligned、full。
- anchors 归一化为所属周期起点后去重，要求 2–6 个周期；baseline 必须属于已选集合。周选择器转换为该周周一，季度转换为季度首日。
- 对比接口返回周期元数据数组、基准、截止日期、比较交易日数、完整度、各期摘要和动态多序列图表数据。每个点包含交易日序号及各周期日期、当日值、累计值和录入状态，不适用值为 null。
- 范围趋势的长区间查询按周期摘要返回，避免返回所有逐日明细；叠加接口仅返回所选周期的明细。
- 非法日期（含 2 月 30 日）、倒置范围、非法粒度或 mode、选择数量越界、无效基准返回 400。沿用 `{ success, data, error }` 响应结构。
- 不新增依赖，不修改 Prisma Schema。

### KPI 界面

- 新增 `KpiAnalysisExplorer.tsx`，接入三种视图、范围选择、周期多选、基准选择及 URL 查询状态；原 `KpiTrendExplorer.tsx` 继续提供单周期功能。
- `KpiAnalysisCharts.tsx` 导出范围柱线图和多周期累计图，通过动态导入加载。
- 点击周期查看每日贡献，可跳转对应日志，也可直接补录/编辑 PTS 和备注，保存后更新趋势。
- 前端只展示和格式化服务端数据，不自行聚合。
- 每日 KPI 保存或补录后重新查询当前视图；删除基准周期时明确将最早剩余周期设为新基准，不保留失效选择。

### 验收

- 查询任意日期范围，分别按周、月、季度展示；核对边界归一化、跨年和长范围。

- 测试跨年周、1 月与上一年 12 月、Q1 与上一年 Q4、闰年、休市日、周期长度不同。
- 测试两期至六期的同进度对齐，历史周期与未结束周期混选；图例隐藏不改变计算口径。
- 测试负 PTS、累计回撤、零/负基准、漏录、全无记录、未来记录忽略，及范围首期的上一期基数查询。
